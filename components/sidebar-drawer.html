Sidebar / Drawer Navigation

Accessible sidebar and drawer patterns with focus trapping, keyboard support, and ARIA attributes.

Design guidelines

UX guidelines

  • Include a clearly visible close button (× or "Close") inside the drawer so mouse and touch users can dismiss it without pressing Escape.
  • The overlay drawer must visually block interaction with background content — do not show interactive background elements through the overlay.
  • Opening or closing the drawer must not cause a content jump or layout shift in the main page area.

Visual design guidelines

  • An overlay drawer must include a visible backdrop that dims the background, making it clear the drawer is in the foreground and blocking interaction with page content behind it.
  • All open and close animations must respect prefers-reduced-motion — provide an instant show/hide alternative for users who have reduced motion enabled.
  • A persistent sidebar must be visually distinct from the main content area — use a background color, border, or shadow so users can tell the sidebar apart from the primary content.

Dev guidelines for web

  • The toggle button must use <button aria-expanded="false" aria-controls="drawer-id">; update aria-expanded to "true" when open and "false" when closed.
  • The drawer element must be a <nav aria-label="…" id="drawer-id"> so it is discoverable as a labeled navigation landmark.
  • For a modal overlay drawer: move focus to the first focusable element inside the drawer on open; trap Tab and Shift+Tab within the drawer; pressing Escape closes the drawer and returns focus to the toggle button.
  • Apply inert (preferred) or aria-hidden="true" to the background content container while the drawer is open, so screen reader users cannot accidentally navigate behind it.
  • Remove inert / aria-hidden from background content when the drawer closes.
  • For a persistent sidebar (always visible), no focus trap is needed — it is always in the natural tab order and requires only a correct landmark label.

Example code

<button
  type="button"
  aria-haspopup="dialog"
  aria-expanded="false"
  aria-controls="side-drawer"
  id="drawer-trigger"
>
  Open menu
</button>

<div
  role="dialog"
  id="side-drawer"
  aria-modal="true"
  aria-labelledby="drawer-title"
  hidden
>
  <h2 id="drawer-title">Navigation</h2>
  <nav aria-label="Main navigation">
    <ul>
      <li><a href="/">Home</a></li>
      <li><a href="/about">About</a></li>
      <li><a href="/contact">Contact</a></li>
    </ul>
  </nav>
  <button
    type="button"
    aria-label="Close navigation menu"
    id="drawer-close"

  </button>
</div>

Dev guidelines for iOS

  • Wrap the drawer container in a Group or ZStack and apply .accessibilityElement(children: .contain) so VoiceOver can navigate into individual drawer items rather than treating the whole drawer as one element.
  • The toggle button must have an .accessibilityLabel("Open navigation menu") and update to "Close navigation menu" when the drawer is open — VoiceOver reads the label at the moment of focus, so it must reflect the current state.
  • Post a UIAccessibility.post(notification: .screenChanged, argument: firstDrawerItem) when the drawer opens to move VoiceOver focus to the first interactive item inside the drawer; post .screenChanged again pointing back to the toggle button when it closes.
  • Apply .accessibilityHidden(true) to the backdrop overlay and any decorative dividers inside the drawer so VoiceOver skips non-interactive chrome and announces only navigation items.
  • Respect the system reduced-motion preference by checking UIAccessibility.isReduceMotionEnabled and skipping the slide-in animation, replacing it with an instant appear.

Example code

import SwiftUI

struct SidebarDrawer: View {
    @State private var isOpen = false
    @Environment(\.accessibilityReduceMotion) var reduceMotion

    var body: some View {
        ZStack(alignment: .leading) {
            // Backdrop
            if isOpen {
                Color.black.opacity(0.4)
                    .ignoresSafeArea()
                    .accessibilityHidden(true)
                    .onTapGesture { closeDrawer() }
            }

            // Drawer panel
            if isOpen {
                VStack(alignment: .leading, spacing: 0) {
                    HStack {
                        Text("Navigation")
                            .font(.headline)
                        Spacer()
                        Button(action: closeDrawer) {
                            Image(systemName: "xmark")
                        }
                        .accessibilityLabel("Close navigation menu")
                    }
                    .padding()

                    NavigationLink("Home", destination: Text("Home"))
                        .padding(.horizontal)
                    NavigationLink("About", destination: Text("About"))
                        .padding(.horizontal)
                    NavigationLink("Contact", destination: Text("Contact"))
                        .padding(.horizontal)

                    Spacer()
                }
                .frame(width: 280)
                .background(Color(.systemBackground))
                .transition(reduceMotion ? .identity : .move(edge: .leading))
                .accessibilityElement(children: .contain)
                .accessibilityLabel("Navigation menu")
            }
        }
        .overlay(alignment: .topLeading) {
            Button(action: openDrawer) {
                Image(systemName: "line.3.horizontal")
            }
            .accessibilityLabel(isOpen ? "Close navigation menu" : "Open navigation menu")
            .padding()
        }
        .animation(reduceMotion ? .none : .easeInOut(duration: 0.25), value: isOpen)
    }

    private func openDrawer() {
        isOpen = true
        UIAccessibility.post(notification: .screenChanged, argument: nil)
    }

    private func closeDrawer() {
        isOpen = false
        UIAccessibility.post(notification: .screenChanged, argument: nil)
    }
}

Dev guidelines for Android

  • Use ModalNavigationDrawer from Material 3; its built-in DrawerState handles open/close state and the scrim automatically, which Compose's semantics layer can surface to TalkBack correctly.
  • Apply Modifier.semantics { contentDescription = "Navigation menu" } on the ModalDrawerSheet so TalkBack announces the drawer as a distinct region rather than reading each child element in isolation on first focus.
  • Set Modifier.semantics { stateDescription = if (drawerState.isOpen) "Open" else "Closed" } on the toggle button so TalkBack announces the current drawer state alongside the button label.
  • Wrap the main content area in a Box with Modifier.semantics { disabled() } applied conditionally while the drawer is open, preventing TalkBack from reaching background content behind the scrim.

Example code

import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.semantics.*

@Composable
fun AccessibleSidebarDrawer() {
    val drawerState = rememberDrawerState(initialValue = DrawerValue.Closed)
    val scope = rememberCoroutineScope()

    ModalNavigationDrawer(
        drawerState = drawerState,
        drawerContent = {
            ModalDrawerSheet(
                modifier = Modifier.semantics {
                    contentDescription = "Navigation menu"
                }
            ) {
                Text(
                    text = "Navigation",
                    modifier = Modifier
                        .padding(16.dp)
                        .semantics { heading() }
                )
                NavigationDrawerItem(
                    label = { Text("Home") },
                    selected = false,
                    onClick = { scope.launch { drawerState.close() } }
                )
                NavigationDrawerItem(
                    label = { Text("About") },
                    selected = false,
                    onClick = { scope.launch { drawerState.close() } }
                )
                NavigationDrawerItem(
                    label = { Text("Contact") },
                    selected = false,
                    onClick = { scope.launch { drawerState.close() } }
                )
            }
        }
    ) {
        // Main content
        Box(
            modifier = if (drawerState.isOpen) {
                Modifier.semantics { disabled() }
            } else {
                Modifier
            }
        ) {
            IconButton(
                onClick = { scope.launch { drawerState.open() } },
                modifier = Modifier.semantics {
                    contentDescription = "Open navigation menu"
                    stateDescription = if (drawerState.isOpen) "Open" else "Closed"
                    role = Role.Button
                }
            ) {
                Icon(Icons.Default.Menu, contentDescription = null)
            }
        }
    }
}
